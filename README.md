# myAI-Assistant-with-voice-trademark
Creating an AI assitant which can carry out my all presentation in my voice as a trademark and also do intercative session with audiences.

[ Audience Input (Speech/Text) ] 
               │
               ▼

               │ (Generates Text Response)
               ▼

               ▼

│ 3. Interactive Visual Front  │ <--- Live Digital Avatar (HeyGen / Tavus)
